
# ai-boundaries

Projeto de estudo e experimentação prática sobre integração de IA em aplicações reais — explorando limites, comportamentos e decisões de arquitetura envolvidas em conectar um modelo de linguagem a um sistema com frontend e backend separados.

## Objetivo

Não é um produto — é um laboratório documentado. A ideia central é testar, na prática, perguntas como:

- Onde e como surgem os limites de uma API de IA (rate limit, tamanho de contexto, custo)?
- Como estruturar corretamente a comunicação entre frontend, backend e um provedor de IA, sem expor credenciais?
- Como manter histórico de conversa de forma correta?
- Como implementar RAG (Retrieval-Augmented Generation) do zero, entendendo cada peça?

## Stack

**Backend**: Node.js + Fastify + Google Gemini API
**Frontend**: React + TypeScript + Vite + Tailwind CSS
